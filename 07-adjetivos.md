## 7.1 Concordancia

Como en español, el adjetivo concuerda en **género** y **número** con el sustantivo.

| | Masculino | Femenino |
|---|---|---|
| Singular | un ami **grand** | une amie **grande** |
| Plural | des amis **grands** | des amies **grandes** |

> Muchas veces el femenino **se escucha** porque hace sonar la consonante final: *grand* "gran" / *grande* "grand".

### Formación del femenino

| Regla | Masculino → Femenino |
|-------|----------------------|
| + **e** | *petit → petite*, *joli → jolie*, *français → française* |
| Ya termina en **-e**: no cambia | *jeune, rouge, facile, sympathique* |
| -**eux** → -**euse** | *heureux → heureuse* (feliz), *sérieux → sérieuse* |
| -**if** → -**ive** | *sportif → sportive*, *actif → active* |
| -**er** → -**ère** | *cher → chère*, *premier → première* |
| -**en** → -**enne** | *italien → italienne*, *ancien → ancienne* |
| -**on** → -**onne** | *bon → bonne* |
| -**el** → -**elle** | *naturel → naturelle* |
| -**c** → -**che** | *blanc → blanche* |

Plural: + **s** (mudo); *-eux* no cambia; *-al* → *-aux* (*national → nationaux*).

## 7.2 Posición

Regla general: **después** del sustantivo, como en español.

*une voiture **rouge*** · *un livre **intéressant*** · *un homme **sympathique***

### Excepción: adjetivos cortos y muy frecuentes van **antes** (regla **BAGS**)

| | Significado | Adjetivos |
|---|---|---|
| **B**eauty | belleza | *beau, joli* |
| **A**ge | edad | *jeune, vieux, nouveau* |
| **G**oodness | bondad / calidad | *bon, mauvais* |
| **S**ize | tamaño | *grand, petit, gros* |

- *un **petit** chat* · *une **belle** maison* · *un **bon** restaurant* · *une **nouvelle** voiture*

> Ante sustantivo plural con adjetivo delante, *des* pasa a **de**: *de **belles** maisons* (en el habla se escucha también *des*).

### Tres adjetivos especiales

Tienen una forma extra delante de sustantivo masculino que empieza con vocal o *h* muda:

| Masc. | Masc. + vocal | Femenino | Plural m. / f. |
|-------|---------------|----------|----------------|
| *beau* | ***bel*** *homme* | *belle* | *beaux / belles* |
| *nouveau* | ***nouvel*** *ami* | *nouvelle* | *nouveaux / nouvelles* |
| *vieux* | ***vieil*** *hôtel* | *vieille* | *vieux / vieilles* |

## 7.4 Comparativos y superlativos

| Estructura | Significado | Ejemplo |
|-----------|-------------|---------|
| **plus** + adj + **que** | más … que | *Paris est plus grand que Lyon.* |
| **moins** + adj + **que** | menos … que | *Le bus est moins cher que le taxi.* |
| **aussi** + adj + **que** | tan … como | *Elle est aussi grande que moi.* |
| **le / la / les plus** + adj | el más … | *C'est la plus belle ville.* |
| **le / la / les moins** + adj | el menos … | *C'est le moins cher.* |

### Irregulares

| | Comparativo | Superlativo |
|---|---|---|
| *bon* (bueno, adjetivo) | **meilleur** (mejor) | **le meilleur** |
| *bien* (bien, adverbio) | **mieux** (mejor) | **le mieux** |

- *Ce gâteau est **meilleur**.* (adjetivo: el pastel es mejor)
- *Elle chante **mieux** que moi.* (adverbio: canta mejor)

---

## 7.5 Demostrativos (este, esta, estos)

| Masculino | Masc. + vocal | Femenino | Plural |
|-----------|---------------|----------|--------|
| **ce** livre | **cet** ami | **cette** table | **ces** livres / tables |

Para distinguir "este" de "aquel", se agrega **-ci** (acá) o **-là** (allá):
*ce livre-ci* (este libro) / *ce livre-là* (ese libro).

## Práctica

**1.** Poné en femenino: a) *un garçon heureux* → une fille ___ · b) *un ami italien* → une amie ___ · c) *un vieux monsieur* → une ___ dame · d) *un homme sportif* → une femme ___

**2.** Ordená y concordá: a) *(maison / grand / une)* · b) *(des / intéressant / livres)* · c) *(un / hôtel / beau)* · d) *(voiture / cette / rouge)*

**3.** Traducí: a) Mi hermano es más alto que yo. · b) Es el mejor restaurante de la ciudad.

<details>
<summary>Soluciones</summary>

**1.** a) *heureuse* · b) *italienne* · c) *vieille* · d) *sportive*

**2.** a) *une grande maison* · b) *des livres intéressants* · c) *un bel hôtel* · d) *cette voiture rouge*

**3.** a) *Mon frère est plus grand que moi.* · b) *C'est le meilleur restaurant de la ville.*

</details>
