# 10. Pasado y futuro

[← Vocabulario esencial](09-vocabulario-esencial.md) · [Índice](README.md) · [Siguiente: Falsos amigos y errores →](11-falsos-amigos-y-errores.md)

Con estas estructuras ya podés hablar de lo que pasó y de lo que va a pasar.

---

## 10.1 Futuro próximo: ***aller* + infinitivo**

Igual que "ir a + infinitivo" en español. Es el futuro más usado en la conversación.

| | |
|---|---|
| je **vais** manger | voy a comer |
| tu **vas** partir | vas a irte |
| il **va** pleuvoir | va a llover |
| nous **allons** voyager | vamos a viajar |
| vous **allez** voir | van a ver |
| ils **vont** arriver | van a llegar |

Negación: *Je **ne** vais **pas** travailler demain.*

---

## 10.2 Pasado reciente: ***venir de* + infinitivo**

Equivale a "acabar de":

- *Je **viens de** manger.* — Acabo de comer.
- *Le train **vient de** partir.* — El tren acaba de salir.

---

## 10.3 *Passé composé* (pretérito perfecto / indefinido)

Es **el** pasado de la conversación. Traduce tanto "comí" como "he comido".

**Estructura:** *avoir* o *être* en presente + **participio pasado**

### Participios regulares

| Infinitivo | Participio | Ejemplo |
|------------|-----------|---------|
| -**er** → **-é** | *parler → parlé* | *J'ai parlé.* |
| -**ir** → **-i** | *finir → fini* | *Tu as fini.* |
| -**re** → **-u** | *vendre → vendu* | *Il a vendu.* |

### Participios irregulares frecuentes

| | | | |
|---|---|---|---|
| *être → **été*** | *avoir → **eu*** | *faire → **fait*** | *prendre → **pris*** |
| *mettre → **mis*** | *dire → **dit*** | *écrire → **écrit*** | *voir → **vu*** |
| *boire → **bu*** | *lire → **lu*** | *pouvoir → **pu*** | *vouloir → **voulu*** |
| *devoir → **dû*** | *savoir → **su*** | *connaître → **connu*** | *ouvrir → **ouvert*** |

### Con *avoir* (la gran mayoría)

| | *manger* |
|---|---|
| j'**ai** mangé | nous **avons** mangé |
| tu **as** mangé | vous **avez** mangé |
| il/elle **a** mangé | ils/elles **ont** mangé |

- *Hier, j'**ai** **fait** du sport.* — Ayer hice deporte.
- *Nous **avons** **vu** un film.* — Vimos una película.

### Con *être*: verbos de movimiento / cambio de estado y todos los pronominales

Unos 16 verbos (y sus derivados). Para recordarlos, pensá en una **casa**: se entra, se sale, se sube, se baja, se nace, se muere…

| | | | |
|---|---|---|---|
| *aller → allé* (ir) | *venir → venu* (venir) | *arriver → arrivé* (llegar) | *partir → parti* (irse) |
| *entrer → entré* (entrar) | *sortir → sorti* (salir) | *monter → monté* (subir) | *descendre → descendu* (bajar) |
| *naître → né* (nacer) | *mourir → mort* (morir) | *rester → resté* (quedarse) | *tomber → tombé* (caer) |
| *retourner → retourné* (volver) | *rentrer → rentré* (volver a casa) | *revenir → revenu* (regresar) | *devenir → devenu* (volverse, llegar a ser) |

**Con *être*, el participio concuerda con el sujeto** (como un adjetivo):

| | *aller* |
|---|---|
| je **suis** allé(e) | nous **sommes** allé(e)s |
| tu **es** allé(e) | vous **êtes** allé(e)(s) |
| il **est** allé / elle **est** allée | ils **sont** allés / elles **sont** allées |

- *Elle **est** **partie** à huit heures.* — Se fue a las ocho.
- *Nous **sommes** **nés** en Argentine.* — Nacimos en Argentina.
- *Je **me suis** **levé(e)** tôt.* — Me levanté temprano. (pronominal → *être*)

> ❌ *J'ai allé* → ✅ *Je suis allé(e)*

### Negación y preguntas en *passé composé*

*ne … pas* rodea al **auxiliar**:

- *Je **n'**ai **pas** mangé.* — No comí.
- *Elle **n'**est **pas** venue.* — No vino.
- *Tu as fini ?* / *Est-ce que tu as fini ?* / *As-tu fini ?*

## 10.4 Introducción al *imparfait* (pretérito imperfecto)

Buena noticia: se usa **casi igual que el imperfecto español** (comía, era, estaba).

**Formación:** raíz de *nous* en presente (sin *-ons*) + terminaciones

*nous parl**ons*** → raíz **parl-**

| | Terminación | *parler* |
|---|---|---|
| je | -ais | parl**ais** |
| tu | -ais | parl**ais** |
| il/elle/on | -ait | parl**ait** |
| nous | -ions | parl**ions** |
| vous | -iez | parl**iez** |
| ils/elles | -aient | parl**aient** |

Único irregular: ***être*** → raíz **ét-**: *j'étais, tu étais, il était, nous étions, vous étiez, ils étaient*.

### ¿*Passé composé* o *imparfait*?

| *Imparfait* (imperfecto) | *Passé composé* (indefinido) |
|--------------------------|------------------------------|
| Descripciones, contexto | Acciones puntuales, terminadas |
| Hábitos en el pasado | Hechos que hacen avanzar la historia |
| *Il **faisait** beau.* (Hacía buen tiempo.) | *Je **suis sorti**.* (Salí.) |
| *Quand j'**étais** petit, j'**habitais** à Salta.* | *En 2020, j'**ai déménagé** à Lyon.* |

Ejemplo combinado:
> *Je **regardais** la télé quand le téléphone **a sonné**.*
> Estaba mirando la tele cuando sonó el teléfono.

---

## 10.5 El futuro simple (para reconocerlo)

Se forma con el **infinitivo** + terminaciones de *avoir*: *-ai, -as, -a, -ons, -ez, -ont*.
*Je parler**ai*** (hablaré), *tu finir**as***, *il prendr**a*** (los -re pierden la *e*).

Irregulares comunes: *être → je **serai***, *avoir → j'**aurai***, *aller → j'**irai***, *faire → je **ferai***, *pouvoir → je **pourrai***, *venir → je **viendrai***.

> A nivel A1 alcanza con el **futuro próximo** (*aller* + infinitivo). Este se trabaja más en A2.

## Práctica

**1.** Pasá al *passé composé*:

a) Je mange une pizza. · b) Nous allons au cinéma. · c) Elle prend le train. · d) Ils voient un film. · e) Tu te lèves à 7 h. · f) Je ne fais pas mes devoirs.

**2.** Futuro próximo: a) Mañana (yo) voy a visitar a mis padres. · b) Va a llover.

**3.** ¿*Imparfait* o *passé composé*?
Quand j'(*être*) ___ petit, j'(*aimer*) ___ le chocolat. Un jour, j'(*manger*) ___ tout le gâteau de ma mère !

**1.** a) *J'ai mangé une pizza.* · b) *Nous sommes allé(e)s au cinéma.* · c) *Elle a pris le train.* · d) *Ils ont vu un film.* · e) *Tu t'es levé(e) à 7 h.* · f) *Je n'ai pas fait mes devoirs.*

**2.** a) *Demain, je vais rendre visite à mes parents.* · b) *Il va pleuvoir.*

**3.** *étais* · *aimais* · *ai mangé*
