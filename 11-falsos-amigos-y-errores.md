El español te da mucha ventaja con el francés, pero también algunas trampas.

## 11.1 Falsos amigos

Palabras que se parecen al español pero significan otra cosa.

| Francés | Significa | No significa | Para decir eso: |
|---------|-----------|--------------|-----------------|
| *attendre* | esperar | atender | *s'occuper de* |
| *rester* | quedarse | restar | *soustraire* |
| *salir* | ensuciar | salir | *sortir* |
| *quitter* | dejar, irse de (un lugar o persona) | quitar | *enlever* |
| *subir* | sufrir, padecer | subir | *monter* |
| *exprimer* | expresar | exprimir | *presser* |
| *molester* | maltratar, agredir | molestar | *déranger, embêter* |
| *entendre* | oír | entender | *comprendre* |
| *embarrassé(e)* | incómodo, avergonzado | embarazada | *enceinte* |
| *constipé(e)* | estreñido | resfriado | *enrhumé(e)* |
| *la carte* | el mapa, la tarjeta, el menú | la carta (correo) | *la lettre* |
| *le sol* | el suelo, el piso | el sol | *le soleil* |
| *la tasse* | la taza | la tasa | *le taux* |
| *le vase* | el jarrón, el florero | el vaso | *le verre* |
| *la firme* | la empresa | la firma | *la signature* |
| *large* | ancho | largo | *long / longue* |
| *la boîte* | la caja, el boliche (*boîte de nuit*) | la bota | *la botte* |
| *la cave* | el sótano, la bodega | la cueva | *la grotte* |
| *débile* | tonto | débil | *faible* |
| *le parfum* | el perfume **y** el sabor (de helado, etc.) | solo "perfume" | *Quel parfum ?* = ¿Qué gusto? |
| *sensible* | sensible | sensato | *raisonnable* |
| *prétendre* | afirmar, sostener | pretender (aspirar) | *aspirer à, vouloir* |

## 11.2 Errores típicos del hispanohablante

### Gramática

| ❌ Incorrecto | ✅ Correcto | Por qué |
|--------------|------------|---------|
| *Suis argentin.* | ***Je** suis argentin.* | El pronombre sujeto es obligatorio. |
| *Je suis 30 ans.* | ***J'ai** 30 ans.* | La edad va con *avoir*. |
| *Je suis faim / froid.* | ***J'ai** faim / froid.* | Ver expresiones con *avoir*. |
| *Je mange pain.* | *Je mange **du** pain.* | Partitivo obligatorio. |
| *Il y a enfants.* | *Il y a **des** enfants.* | El plural indefinido lleva *des*. |
| *Je n'ai pas un chien.* | *Je n'ai pas **de** chien.* | Tras negación: *de*. |
| *Je ne parle français.* | *Je ne parle **pas** français.* | La negación tiene dos partes. |
| *J'ai allé au cinéma.* | ***Je suis allé(e)** au cinéma.* | *Aller* forma el pasado con *être*. |
| *Elle est allé.* | *Elle est allé**e**.* | Con *être*, el participio concuerda. |
| *Je vais à France.* | *Je vais **en** France.* | Países femeninos: *en*. |
| *Je vais à le cinéma.* | *Je vais **au** cinéma.* | Contracción obligatoria. |
| *Je suis un professeur.* | *Je suis professeur.* | Profesión sin artículo tras *être*. |
| *Il est un bon ami.* | ***C'est** un bon ami.* | *C'est* + determinante + sustantivo. |
| *ma amie* | ***mon** amie* | *mon* ante vocal, aunque sea femenino. |

### Uso de verbos

| ❌ | ✅ | Comentario |
|----|----|-----------|
| *Je suis en train de…* para todo | *Je mange.* | El presente simple ya expresa "estoy comiendo". |
| *Je prends une décision* ✅ / *Je fais une décision* ❌ | *prendre une décision* | Algunas colocaciones cambian. |
| *Je pose une question* ✅ / *Je fais une question* ❌ | *poser une question* | "Hacer una pregunta". |
| *Je te manque* (quiero decir "te extraño") | *Tu **me** manques.* | Estructura invertida: "tú me faltas". |

### Pronunciación

| Error | Corrección |
|-------|-----------|
| Pronunciar las consonantes finales (*petit* "petit") | Son mudas: "pti" (salvo C, R, F, L). |
| Pronunciar la *-ent* verbal (*ils parlent* "parlent") | Es muda: "il parl". |
| Decir **u** española en *tu, rue* | Es `[y]`: "i" con labios de "u". |
| No distinguir *dessus / dessous*, *rue / roue* | Practicar pares **u** vs **ou**. |
| Pronunciar la *n* de las nasales (*bon* "bon") | La *n* no suena; la vocal es nasal. |
| *s* entre vocales sorda (*maison* "meson") | Es sonora `[z]`: "mezón". |
| Confundir **b** y **v** | En francés son distintas: *vin* (vino) ≠ *bain* (baño). |
| Pronunciar la *h* | Siempre muda. |
| Acentuar como en español (*ca-FÉ-te-ri-a*) | Acento en la última sílaba: *ca-fé-té-RIA*. |

## 11.3 Consejos para seguir avanzando

1. **Escuchá francés todos los días**, aunque no entiendas todo: podcasts, series con subtítulos en francés, música.
2. **Leé en voz alta** 5 minutos por día para conectar escritura y sonido.
3. **Aprendé frases enteras**, no palabras sueltas: *j'ai besoin de…*, *je voudrais…*, *est-ce que je peux… ?*
4. **Llevá un cuaderno** de errores propios y repasalo.
5. **Hablá desde el primer día**, aunque sea solo: describí lo que hacés (*Je prépare le café. Je bois…*).
6. Al terminar esta guía, el siguiente paso es el nivel **A2**: pronombres complemento (*le, la, lui, y, en*), futuro simple, condicional y *imparfait* a fondo.

**Bon courage !** 🇫🇷
