## 2.1 *Tu* o *vous*

El francés distingue entre trato informal y formal, como *tú/vos* y *usted*:

| | Cuándo usarlo |
|---|---|
| **tu** | Amigos, familia, niños, compañeros jóvenes, mascotas |
| **vous** | Desconocidos, adultos que no conocés, en un negocio, en el trabajo; también es el **plural** de "tú" (ustedes) |

> Ante la duda, usá **vous**. Si la otra persona quiere tutearte, te lo va a proponer: *On peut se tutoyer ?* (¿Nos tuteamos?).

## 2.2 Saludar y despedirse

| Francés | Español | Registro |
|---------|---------|----------|
| *Bonjour* | Buen día / Buenas tardes | Neutro, durante el día |
| *Bonsoir* | Buenas noches (al llegar) | Neutro, desde la tarde-noche |
| *Salut* | Hola / Chau | Informal |
| *Coucou* | ¡Holi! | Muy informal |
| *Au revoir* | Adiós | Neutro |
| *Bonne journée* | Que tengas un buen día | Al despedirse de día |
| *Bonne soirée* | Que tengas una buena noche | Al despedirse de noche |
| *Bonne nuit* | Buenas noches (antes de dormir) | |
| *À bientôt* | Hasta pronto | |
| *À demain* | Hasta mañana | |
| *À plus (tard)* | Hasta luego | Informal |

> En Francia es de mala educación entrar a un negocio o hablarle a alguien sin decir antes **Bonjour**.

## 2.3 Cortesía

| Francés | Español |
|---------|---------|
| *Merci* / *Merci beaucoup* | Gracias / Muchas gracias |
| *De rien* | De nada |
| *Je vous en prie* / *Je t'en prie* | No hay de qué (más formal) |
| *S'il vous plaît* / *S'il te plaît* | Por favor (formal / informal) |
| *Excusez-moi* / *Excuse-moi* | Disculpe / Disculpá (para llamar la atención) |
| *Pardon* | Perdón (al chocar, pasar, o para pedir que repitan) |
| *Désolé(e)* | Lo siento |
| *Oui* / *Non* | Sí / No |
| *D'accord* | De acuerdo / Dale |

## 2.4 ¿Cómo estás?

| Pregunta | Respuesta |
|----------|-----------|
| *Comment allez-vous ?* (formal) | *Je vais bien, merci. Et vous ?* |
| *Comment vas-tu ?* / *Comment ça va ?* | *Très bien, merci. Et toi ?* |
| *Ça va ?* (informal) | *Ça va.* / *Ça va bien.* / *Bof…* (más o menos) / *Pas mal.* (nada mal) |

## 2.5 Presentarse

| Francés | Español |
|---------|---------|
| *Je m'appelle Ana.* | Me llamo Ana. |
| *Comment tu t'appelles ?* / *Comment vous appelez-vous ?* | ¿Cómo te llamás? / ¿Cómo se llama usted? |
| *Enchanté.* / *Enchantée.* | Encantado. / Encantada. |
| *Je suis argentin.* / *Je suis argentine.* | Soy argentino. / Soy argentina. |
| *Je viens d'Argentine.* | Vengo de Argentina. |
| *J'habite à Buenos Aires.* | Vivo en Buenos Aires. |
| *J'ai trente ans.* | Tengo treinta años. |
| *Je suis étudiant(e) / ingénieur(e) / professeur(e).* | Soy estudiante / ingeniero(a) / profesor(a). |
| *Je parle espagnol et un peu français.* | Hablo español y un poco de francés. |

> Las profesiones y nacionalidades van **sin artículo** después de *je suis*: *Je suis médecin* (no ❌ *Je suis un médecin*). Las nacionalidades se escriben en **minúscula** como adjetivo (*argentin*), pero en mayúscula como sustantivo (*un Argentin*).

## 2.6 Frases de supervivencia

| Francés | Español |
|---------|---------|
| *Je ne comprends pas.* | No entiendo. |
| *Pouvez-vous répéter, s'il vous plaît ?* | ¿Puede repetir, por favor? |
| *Pouvez-vous parler plus lentement ?* | ¿Puede hablar más despacio? |
| *Parlez-vous espagnol / anglais ?* | ¿Habla español / inglés? |
| *Comment dit-on « … » en français ?* | ¿Cómo se dice "…" en francés? |
| *Qu'est-ce que ça veut dire ?* | ¿Qué significa eso? |
| *Comment ça s'écrit ?* | ¿Cómo se escribe? |
| *Je ne sais pas.* | No sé. |
| *Où sont les toilettes ?* | ¿Dónde está el baño? |
| *Combien ça coûte ?* / *C'est combien ?* | ¿Cuánto cuesta? |
| *Je voudrais un café, s'il vous plaît.* | Quisiera un café, por favor. |
| *L'addition, s'il vous plaît.* | La cuenta, por favor. |
| *Au secours !* | ¡Socorro! |

## 2.7 Diálogo modelo

> — **Bonjour !** Je m'appelle Lucas. Et vous ?
> — Bonjour. Je m'appelle Camille. **Enchantée.**
> — Enchanté. Vous êtes française ?
> — Oui, je suis de Lyon. Et vous ?
> — Je suis argentin. J'habite à Córdoba.
> — Ah, super ! Vous parlez bien français.
> — Merci, mais je suis débutant. Pouvez-vous parler plus lentement, s'il vous plaît ?
> — Bien sûr ! *(¡Por supuesto!)*

## Práctica

Traducí al francés:

1. Buenas noches (llegando a una cena), me llamo Sofía.
2. ¿Cómo está usted?
3. No entiendo, ¿puede repetir por favor?
4. Soy argentina y vivo en Rosario.
5. Gracias. — De nada. Hasta mañana.

<details>
<summary>Soluciones</summary>

1. *Bonsoir, je m'appelle Sofía.*
2. *Comment allez-vous ?*
3. *Je ne comprends pas, pouvez-vous répéter, s'il vous plaît ?*
4. *Je suis argentine et j'habite à Rosario.*
5. *Merci. — De rien. À demain.*

</details>

> Nota tipográfica: en francés de Francia se deja un **espacio antes de `? ! : ;`** y se usan comillas « así ».
