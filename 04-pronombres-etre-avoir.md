# 4. Pronombres, *être* y *avoir*

[← Artículos](03-articulos-y-sustantivos.md) · [Índice](README.md) · [Siguiente: Verbos en presente →](05-verbos-presente.md)

---

## 4.1 Pronombres personales sujeto

| Francés | Español | Notas |
|---------|---------|-------|
| **je** (j') | yo | *j'* ante vocal: *j'ai*, *j'habite* |
| **tu** | tú / vos | informal |
| **il** | él | también para cosas masculinas |
| **elle** | ella | también para cosas femeninas |
| **on** | uno / nosotros (coloquial) | se conjuga como *il* |
| **nous** | nosotros/as | |
| **vous** | usted / ustedes / vosotros | formal o plural |
| **ils** | ellos | también grupo mixto |
| **elles** | ellas | solo si todos son femeninos |

> **Clave:** en francés el pronombre sujeto es **obligatorio**. En español decimos "hablo"; en francés hay que decir *je parle*. ❌ *Parle français.*

### *On*, el pronombre más usado en la conversación

En el habla cotidiana, **on** reemplaza casi siempre a *nous*:

- *On va au cinéma ?* — ¿Vamos al cine?
- *On mange à huit heures.* — Comemos a las ocho.

También significa "uno / se" impersonal: *Ici, on parle français.* — Aquí se habla francés.

---

## 4.2 *Être* (ser / estar)

Un solo verbo para **ser** y **estar**.

| | *être* | Pronunciación |
|---|---|---|
| je | **suis** | "süi" |
| tu | **es** | "e" |
| il / elle / on | **est** | "e" |
| nous | **sommes** | "som" |
| vous | **êtes** | "et" |
| ils / elles | **sont** | "son" nasal |

- *Je suis fatigué.* — Estoy cansado.
- *Elle est médecin.* — Es médica.
- *Nous sommes à Paris.* — Estamos en París.
- *Vous êtes français ?* — ¿Usted es francés?

---

## 4.3 *Avoir* (tener / haber)

| | *avoir* | Pronunciación |
|---|---|---|
| j' | **ai** | "e" |
| tu | **as** | "a" |
| il / elle / on | **a** | "a" |
| nous | **avons** | "avón" (con *liaison*: "nu**z**avón") |
| vous | **avez** | "avé" ("vu**z**avé") |
| ils / elles | **ont** | "on" nasal ("il**z**ón") |

> Atención a *ils **sont*** `[ilsɔ̃]` (son, con *s* sorda) vs *ils **ont*** `[ilzɔ̃]` (tienen, con *z* sonora). Solo los distingue la *liaison*.

### Expresiones con *avoir* donde el español usa "tener" o "estar"

| Francés | Español |
|---------|---------|
| *avoir … ans* | tener … años — *J'ai 25 ans.* (❌ *Je suis 25 ans*) |
| *avoir faim / soif* | tener hambre / sed |
| *avoir chaud / froid* | tener calor / frío |
| *avoir sommeil* | tener sueño |
| *avoir peur (de)* | tener miedo (de) |
| *avoir raison / tort* | tener razón / estar equivocado |
| *avoir besoin de* | necesitar — *J'ai besoin d'aide.* |
| *avoir envie de* | tener ganas de — *J'ai envie de dormir.* |
| *avoir mal à* | doler — *J'ai mal à la tête.* (Me duele la cabeza.) |

## 4.4 *Il y a* (hay)

*Il y a* es invariable, para singular y plural:

- *Il y a un problème.* — Hay un problema.
- *Il y a des gens.* — Hay gente.
- *Il n'y a pas de pain.* — No hay pan.
- *Il y a deux ans.* — Hace dos años.

---

## 4.5 *C'est* / *Ce sont* (es / son)

Para presentar o identificar algo:

- *C'est mon frère.* — Es mi hermano.
- *Ce sont mes amis.* — Son mis amigos. (en el habla, se escucha también *c'est mes amis*)
- *C'est beau !* — ¡Qué lindo!
- *Qu'est-ce que c'est ?* — ¿Qué es esto?

> **C'est** + determinante + sustantivo: *C'est un médecin.*
> **Il/Elle est** + adjetivo o profesión sin artículo: *Il est médecin.* *Elle est sympa.*

---

## 4.6 Pronombres tónicos

Se usan después de preposición, para enfatizar o solos:

| je | tu | il | elle | nous | vous | ils | elles |
|---|---|---|---|---|---|---|---|
| **moi** | **toi** | **lui** | **elle** | **nous** | **vous** | **eux** | **elles** |

- *Moi, je suis argentin.* — Yo soy argentino.
- *Et toi ?* — ¿Y vos?
- *Avec lui.* — Con él.
- *C'est pour eux.* — Es para ellos.
- *Chez moi.* — En mi casa.

---

## 4.7 Posesivos (mi, tu, su…)

Concuerdan con **lo poseído**, no con el poseedor.

| Poseedor | Masc. sing. | Fem. sing. | Plural |
|----------|-------------|------------|--------|
| je | **mon** | **ma** | **mes** |
| tu | **ton** | **ta** | **tes** |
| il / elle | **son** | **sa** | **ses** |
| nous | **notre** | **notre** | **nos** |
| vous | **votre** | **votre** | **vos** |
| ils / elles | **leur** | **leur** | **leurs** |

- *mon père, ma mère, mes parents*
- *son livre* = su libro (de él **o** de ella)
- *sa voiture* = su auto (de él **o** de ella)

> Ante un sustantivo femenino que empieza con vocal se usa **mon/ton/son**: *mon amie*, *ton école*, *son histoire*.

## Práctica

**1.** Conjugá *être* o *avoir*:

a) Nous ___ argentins. · b) J'___ faim. · c) Ils ___ deux enfants. · d) Tu ___ fatigué ? · e) Elle ___ 30 ans. · f) Vous ___ raison.

**2.** Traducí:

a) Mi hermana tiene frío. · b) Hay un gato en la cocina. · c) Es mi amiga Julie. · d) Su casa (de ellos) es grande.

<details>
<summary>Soluciones</summary>

**1.** a) *sommes* · b) *ai* · c) *ont* · d) *es* · e) *a* · f) *avez*

**2.** a) *Ma sœur a froid.* · b) *Il y a un chat dans la cuisine.* · c) *C'est mon amie Julie.* · d) *Leur maison est grande.*

</details>
